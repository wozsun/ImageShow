# ImageShow 版本规划

> 版本与 TODO 规则见 [交付规范](../spec/delivery.md)。

1. 直接读取 `TODO.md` 的实际内容，据此核对当前实现、技术依赖和验收边界。
2. 选择一个目标或一组职责紧密、共享验收边界的目标；必要时给出简短版本建议。
3. 用户要求详细方案时，按交付规范的 [TODO 与方案](../spec/delivery.md#todo-与方案)确定存放方式；采用独立文件时，先整理方案文件。
4. 按用户最终确认的版本和范围整理 TODO，保留未完成事项及待验收项；有新的重大影响先说明。已有独立方案时，在对应条目保留摘要与方案链接。
5. 输出本次范围与验收要点；用户授权开发后进入 [开发流程](development.md)。
