# 随机图实现

修改 `/random`、公开列表随机排序或标签表达式时读取。对外参数与返回见公开文档 `docs/api/random.md`；具体额度与预算以代码中的策略常量为准。

## 请求边界

- 顺序固定：频次计数 → 参数格式与数量校验 → 词表、缓存与存储访问。计数先于校验且失败不退还，计数只读取 `limit` 的数值（重复时取第一个非空值，与解析同源）；所有格式校验先于任何查询。
- 参数的范围、筛选、取图三层之间与层内自由组合，没有互斥。判断是否报错的标准：有唯一明确含义且照此执行不会悄悄返回与所求不同的结果就接受。仍报错的是含义不唯一或会掩盖调用方错误的写法：`limit` 大于 1 而非显式 json（跳转与代理只能回一张，且计数已按张数扣额度）、`limit=0`、取值不同的重复单值参数、未知参数（防止写错参数名后筛选被悄悄丢掉）、`tag` 排除写法（尚未支持）。
- `brightness=all` 与省略共用去重与 seed 签名。主题、作者的包含与排除可混写，在映射为 slug 后归一成“包含减排除”再生成筛选计划，因为每张图只有一个主题和作者；画廊的筛选计划仍拒绝混写。
- `seed`、`id` 的空值仍为 400，避免固定或定向选图静默退化为完全随机。标签空项在随机入口压缩，shared 解析器仍拒绝空项，因为画廊 URL 往返依赖它。
- 缺省 `device` 与显式 `auto` 是同一规范状态，共享候选、近期去重签名与缓存 key。纯 UA 规则位于 shared，Server 与 Web 共用。
- 未知名称不得进入筛选计划、派生索引 key、近期去重或 seed 签名，否则任意错名都能触发索引构建或制造新 key；包含项或标签表达式因此为空时直接 404，不访问缓存与存储。画廊仍按自身规则处理未知名称。
- 标签表达式的最终候选按图片去重，命中多条条件不增加权重，也不先随机选分支。额度按规范化后的词项计数（去除同子句重复词与完全相同子句），不做布尔化简。列表、统计与随机共用表达式与执行签名，各自有独立预算。

## 频次与白名单

- 图片额度与批量次数两个窗口由 GET / HEAD 与全部模式共用；余量不足时整笔拒绝且计数不变。
- Referer 豁免计数的白名单与图片防盗链同源，不另建第二份；它只是轻量约束，不是鉴权。
- 非白名单请求依赖 Redis 计数，计数失败返回 `503 redis_unavailable`；白名单请求在 Redis 完全不可用时仍可经 PG 有界回源。IP 依赖可信代理覆盖的单值头，缺失时共用 `unknown` 额度。

## 选图

- 普通随机在所需派生索引存在时不访问 PG，不使用 `ORDER BY random()` 或 count + offset：从筛选 ZSET 抽取成员并批量读取 rich item，应用层打乱后优先避开同一客户端的近期记录。单次响应 UUID 唯一；近期去重是尽力而为，不承诺完整轮次。近期历史写入失败只降低去重效果。
- 派生属性索引按需构建：首次使用某属性的请求立即走 PG fallback，并触发后台有界构建，请求不等待构建。超出容量的构建放弃整份结果，不截断候选。
- PG fallback 用有界索引探针取得 UUIDv7 时间范围，再取随机 pivot 按 `id` 读取并在不足时从头 wrap；候选有上限，仍优先避开可读的 Redis 近期历史。Redis 完全断线时不建立替代历史，允许跨请求重复。
- 固定 seed：相同 seed、规范化筛选签名与候选集合产生相同有序序列，不受 IP、访问次数、近期历史、返回模式、尺寸或重启影响；Redis 与 PG 两条路径必须产生相同顺序。seed 不进入索引 key，不读写近期历史，不保存持久绑定。公开列表的 random 排序与 seed 共用同一窗口读取。
- 定向 `id`：Redis 不可读时直接查 PG；候选有硬上限，超出返回 503 而不是截断；不回退到完整随机集合，不使用筛选索引，也不触发派生索引构建。筛选在读回的有界候选上用 `imageMatchesFilterPlan` 完成，它是 `buildImageFilterSql` 的内存形式，三条路径的筛选含义必须一致；设备不跨设备回退。
- 定向取图带 seed 时按“seed + 图片 ID”的哈希排序：结果只取决于候选集合，Redis 与 PG 天然一致。普通 seed 的环形窗口算法不用于定向请求，因为定向候选不在筛选索引中。
- `size` 只选择已生成的档位，不动态缩放，也不影响筛选、seed 或近期去重。

## 响应

- 主站 `/random` 的 CORS 中间件装配在 Host / 冷启动边界之前，以覆盖合法主站请求的拒绝响应；显式域名下的未知 Host 不获得 CORS。`OPTIONS` 不计数、不校验、不选图。
