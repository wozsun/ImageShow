# 超级管理员指南

超级管理员对应后台 `super` 角色，拥有图片管理员的全部能力，并负责应用内的账号、配置、
存储与高风险维护。首次空库启动时由实例维护者通过 `ADMIN_USERNAME` 和
`ADMIN_PASSWORD` 创建第一个超级管理员。

## 应用内管理

- 完成图片管理员的全部上传 / 导入、编辑、分类、移入回收站、恢复和只读检查工作。
- 创建、重置或删除图片管理员账号；超级管理员自身不能在用户管理页被删除。
- 在站点配置页修改全部应用运行设置。
- 管理内置 local 与 S3 后端的显示名、连接测试、默认项和启停，并新增或配置 S3 后端。
- 使用数字控件调整存储后端排序：越大越靠前，同值按 slug 升序；local 固定首位，不提供排序编辑。
- 查看应用日志与检查结果，并在明确确认后执行维护操作。

## 高风险操作

以下操作会改变对象位置、永久数据或派生状态，执行前应先阅读预览与检查结果：

- 迁移一张、多张图片或整个存储后端。
- 永久删除选中回收站图片，或清空回收站。
- 删除主题、标签或作者；确认窗口的关联数量包含回收站，删除会解除所有关联。
- 通过单一“存储维护”操作从同档一致副本恢复三档缺失对象、清理无引用对象并维护持久彻底删除任务。
- 手动重建统一图片缓存。

永久删除回收站内容时，先点击“永久删除”，再点击“确认删除”才提交；执行中显示“正在删除”，
正常情况下弹窗会等待该范围全部删除完成。
图片管理员账号与存储后端的删除同样采用三级操作：点击卡片入口打开弹窗，点击“确认删除”后
进入最终确认状态，再点击“再次确认”才提交；最终确认按钮失焦时取消该确认状态。
精确权限与请求安全见[安全](../security.md)，维护预览、锁和对象归属见
[存储](../storage.md)。

## 站点配置

「设置 → 站点配置」包含站点信息、首页、画廊与展映、外部嵌入、上传与导入、图片处理、
后台界面、登录与请求限制、登录验证和运行日志。逐项含义和生效规则见[配置说明](../../CONFIG.md)。
配置按用途分组，卡片高度随内容调整；多行文本默认占两个单行配置的高度，窄屏时按单列排列。
模块启用开关位于对应卡片或分组的标题右侧；根路径页面与首页浏览按钮目标集中在“首页入口”。
有数值边界的字段显示允许范围，清空输入时也显示范围提示；关联字段仍在保存时统一校验。
页面维护一份完整草稿，点击“保存应用配置”后统一校验、持久化并应用到后续操作；保存失败保留草稿。
更改站点域名前先完成域名接入，确认保存后可能需要从新域名重新登录。

直接编辑 `data/config.json` 后点击“读取配置文件”；存在未保存修改时先确认替换。
读取失败不会丢失草稿。存储连接与凭据由存储管理页维护，数据库与对象备份由实例维护者负责。
配置交接的技术边界见[功能与流程](../flows.md#配置缓存与-worker-的交接)。

## 与实例维护者的边界

超级管理员管理的是 ImageShow 应用内部。Docker、Compose、反向代理、宿主机目录、数据库
备份、容器启停和故障恢复属于[实例维护者](./instance-maintainer.md)，不能通过后台页面代替。
