# 图片管理员指南

图片管理员对应后台 `image` 角色，负责日常图片与词表维护，可查看实例检查结果。

后台图片详情与回收站可打开已登记的独立外部原图，访问时须保持管理员登录。
管理员登录后，在公开画廊、展映及其嵌入页的图片详情中也可使用原图按钮；访客不显示该按钮。

## 图片接入与编辑

1. 使用本地文件上传，或通过 HTTPS URL、JSONL、微博导入图片。
2. 查看待提交任务的预览、重复提示与属性；确认后提交入库。关闭窗口后仍可重新打开，继续处理服务端保留的任务。
3. 在图库或无主题视图中筛选图片，选择一张或多张进行编辑；回收站图片须先恢复。
4. 修改标题、设备、亮度、主题、标签、作者、来源和描述；保存后以服务端结果为准。

列表可按图片时间或入库时间选择最新 / 最旧顺序，排序偏好按账号保存。
主题和作者支持包含 / 排除，标签支持“任一 / 全部”。“清空”会清除分类条件和选择、返回第一页，保留当前视图。
图片列表的主题、标签、作者筛选可按名称或 slug 搜索，支持忽略英文大小写和按顺序匹配部分字符；中文名称也支持全拼、首字母、混合缩写和多音字读音，并高亮对应原文。例如“城市夜景”可用 `chengshiyejing`、`csyj` 或 `yejing` 查找。直接文字匹配优先，选择后仍使用原词条 slug。
输入法选词期间保留上一条搜索的结果与高亮，文字确认上屏后再搜索；直接输入英文字母仍即时匹配。

上传、导入和批量编辑的默认属性栏共用“应用到全部”：只应用已填写属性，标签追加并去重，空输入不清空已有值。
箭头菜单提供清空全部主题、标签、作者或这三项的操作；确认后只影响本次捕获的可修改任务。
批量编辑中的清空先修改草稿，保存后生效，保存前可复原。

单张任务的主题留空表示清除主题；顶部默认主题留空表示不覆盖已有主题。`null` 是未设置主题的保留值，不能创建同名词条。

## 回收站与词表

- 图库和编辑窗口的删除按钮需要在同一按钮上再次确认；失焦或点击其他位置会取消确认。
- 移入回收站后图片不再被公开站点发现，但既有媒体直链仍可访问。图片管理员可以恢复图片。
- 可新建、编辑、排序主题、标签和作者。新建词条优先显示，已存在的词条不会因再次采用而重排。
- 三类词条的图片数量均为全部关联图片，包含回收站；移入或恢复回收站不会改变这个数量。
- 排序数字越大越靠前，同值按 slug 升序；允许 -5,000,000 至 5,000,000 的整数。输入后按 Enter 或离开控件保存，失败时保留草稿。

接入、重复处理、取消与重试的详细规则见[图片接入流程](../ingestion.md)，编辑与回收站规则见[后台管理](../flows.md#后台管理)。

## 检查与权限

可查看 PostgreSQL、Redis、图片投影、存储和回收站一致性检查，也可修改自己的密码与外观偏好。
发现问题时，将检查结果交给超级管理员处理。

以下操作由超级管理员执行，图片管理员不能通过页面或直接 API 请求获得权限：

- 迁移图片或整个存储后端。
- 永久删除图片、清空回收站，或删除主题、标签、作者。
- 执行存储维护、对象清理或图片缓存手动重建。
- 管理用户、存储后端、站点配置、高级配置与日志。

权限明细见[安全](../security.md)，对象与迁移规则见[存储](../storage.md)。
