# 图片管理员指南

图片管理员对应后台 `image` 角色，负责日常图片与词表维护。该角色可以查看实例检查
结果，但不拥有会改变存储位置、永久删除数据或修改实例配置的高风险权限。

## 日常工作

- 通过本地文件执行 Upload，或通过 HTTPS URL、JSONL、微博来源执行 Import。
- 在图片列表按图库、无主题、回收站及各分类筛选，选择一张或多张图片进行编辑。
- 使用工具栏双分区排序控件：左侧切换图片 / 入库时间，右侧切换最新 / 最旧；切换后保留筛选并返回第一页，选择按账号记住并在下次进入时恢复。
- 修改标题、设备、亮度、主题、标签、作者、来源和描述。
- 将图片移入回收站或恢复；进入回收站后不再被站点发现，但既有媒体直链仍可访问。
- 查看、新建、编辑和排序主题、标签与作者。
- 查看 PostgreSQL、Redis、图片投影与存储检查，以及“全部”中的回收站一致性结果。
- 修改自己的密码，保存外观和图片列表排序偏好。

新建主题、标签和作者显示在各自列表最前面，已有词条的相对顺序保持不变；上传、导入或编辑
图片时自动建立的词条也遵循同一规则。同次新增的多个标签按输入顺序排列在前，重复采用已有
词条不会把它移到首位。排序值达到 5,000,000 时，新词条使用该上限并按 slug 升序排列。

词表卡片的 `[−] [数字] [＋]` 控件直接编辑排序值，数值越大越靠前，同值按 slug 升序。
允许 -5,000,000 至 5,000,000 的整数；聚焦数字框自动全选，加减或输入时先保留草稿，按 Enter 或焦点移出整个控件后保存，成功后按服务器结果排列。
在控件内部切换焦点不保存，失败保留输入并在右上角显示红色消息弹窗；鼠标悬浮加减按钮可查看各自的调整方向。
上传或导入任务中已自动带入的主题可以在任务卡片里直接清空，草稿同步以 `null` 表示未设置主题，
无需填写特殊词；主题输入中的 `null` 同样表示留空，不能创建同名主题标识。顶部默认主题留空
仍表示不覆盖任务现有主题；批量清空使用“清空全部主题”。

图库、无主题和回收站中的标签筛选均提供“任一 / 全部”。全部要求图片具有所有已选标签，
允许同时具有其他标签；主题和作者仍提供包含 / 排除。标签筛选方式不改变编辑或批量赋值语义。

主题、标签和作者的筛选、图片编辑及上传 / 导入候选共用名称和 slug 搜索：忽略英文大小写，
支持顺序不变的非连续字符，例如 `hz`、`hg` 匹配 `hangzhou`，“风夜”匹配“风景夜色”。
完整匹配优先，其次为连续匹配、非连续匹配，同级保留词表顺序，匹配字符加粗显示。
选择候选后采用该词条的真实 slug；编辑框中直接输入合法新 slug 的现有新建方式保持不变。
筛选候选添加成功后清空搜索词，保持菜单展开并将焦点送回输入框；添加失败、移除已选项或切换方式时保留搜索词。

图片列表的“清空”会一次移除设备、亮度、主题、标签和作者筛选，但保留当前图库 / 无主题 /
回收站视图；随后清除选择与瞬时反馈、回到第一页并滚动到列表顶部。即使在无主题视图中看不到
先前保留的主题条件，该条件也会一起清除。五项均为空时只有“清空”不可用，筛选入口仍可打开；
页面忙碌时两者都会暂时禁用。移动端清空已展开筛选时，内部菜单会收起，外层面板保持展开。
短宽且短高的滚动面板不另设内部收起按钮，仍使用顶部“筛选”主段收起。

单图编辑、移入回收站和恢复与批量操作共用同一套 `1..N` 流程；只有窗口标题、分页和批量
默认值等展示差异。详细操作与失败收敛见[功能与流程](../flows.md#后台管理)。
图片卡片上的单图删除按钮需在同一个按钮内点击两次才会执行；第一次点击后失焦或点击其他
位置会取消确认。图库 / 无主题的批量删除也在同一个文字按钮内由“批量删除”切换为“确认删除”，
不打开弹窗；提交后单图按钮保持“删除中”，批量按钮显示“正在删除”，两处都禁止重复提交。
图片编辑窗口内的单张和批量删除同样在图标按钮内点击两次确认；批量提示显示当前活动图片数量，
失焦或点击按钮外会取消确认，第二次点击才将这些图片移入回收站。

上传、导入和批量编辑的默认属性栏共用“应用到全部”分体按钮。主按钮只应用已填写的属性，
标签追加并去重，空输入不清空已有属性。箭头菜单依次提供“清空全部主题”“清空全部标签”
“清空全部作者”和“清空以上全部”；最后一项只同时清空主题、标签和作者，保留设备、亮度、
标题、来源等其他图片信息，不删除图片或分类词条。选定动作后先确认范围和数量，取消不会修改。
队列清空仅作用于本次捕获的可修改任务；已锁定或已离队任务跳过，后来加入的任务不受影响。
批量编辑清空先修改本次选中图片的草稿，点击“保存”后生效，也可在保存前“复原”。
移动端的菜单和确认窗口属于默认属性面板，Escape 依次关闭最上层窗口、菜单或展开面板，
焦点回到仍可用的触发控件；确认窗口通过取消按钮或 Escape 取消。

## 不能执行的操作

以下能力只授予超级管理员，图片管理员页面会隐藏或禁用入口，服务端也会独立返回 403：

- 单图、批量或整后端存储迁移。
- 永久删除选中图片或清空回收站。
- 删除主题、标签或作者。
- 执行存储维护、对象清理或图片缓存手动重建。
- 管理用户、存储后端、站点配置、高级配置与日志。

检查页的只读结果不等于维护授权；发现缺失缩略图、孤儿对象或缓存异常时，应把检查结果
交给超级管理员确认。权限明细与接口强制边界见[安全](../security.md)，图片对象和迁移规则
见[存储](../storage.md)。
