# 普通用户指南

公开站点无需后台账号，可浏览、筛选、分享和读取随机图片。站点管理员决定开放哪些页面与嵌入入口。

## 浏览与筛选

- **首页**：查看推荐内容和分类入口。
- **画廊**：通过工具栏的“筛选”打开五属性目录，桌面端排序也在工具栏中；移动端排序与返回顶部位于右下角，返回顶部在上、排序在下。点击“画廊”导航会重新读取列表并回到顶部；浏览器返回时可恢复最近一次匹配的浏览位置，整页刷新不恢复。
- **展映**：桌面工具栏可切换瀑布流 / 漂浮与排列顺序；缩小、放大和复原位于筛选左侧，暂停 / 继续位于分享左侧，761–900px 的模式切换位于“画面”菜单。760px 及以下顶部只保留筛选和分享，不显示条件摘要；底部两侧竖排，左侧从上到下为复原、放大、缩小，右侧为排列顺序、暂停 / 继续、画面切换。底部按钮沿用公开页面的尺寸、配色与显隐效果，外观为方形圆角；导航收起后先变淡，停留 5 秒后进一步淡出，悬停或键盘聚焦时恢复。移动端排序按钮依次切换随机模式、最新优先、最旧优先；画面按钮切换瀑布 / 漂浮。同屏图片较多时，请根据设备性能调整数量。
- **筛选入口**：无条件时显示“筛选”，有条件时显示等宽的“重新筛选｜清空”；左侧重新打开筛选，右侧直接清空已应用条件。
- **条件摘要**：显示已选设备、明暗的具体选项，以及主题、标签、作者的已选数量，不展开词条名称；不同维度以 `·` 分隔，排除条件标注“排除”。同一标签属于多个组时只计一次，未选维度不显示，无条件时显示“全部图片”。公开筛选弹窗、已选栏与工具栏摘要将设备分类显示为“横版图片 / 竖版图片”，对应原有 pc / mb 分类。
- **排列顺序**：可选择“随机模式”“最新优先”或“最旧优先”，切换时保留筛选条件。
- **详情**：查看标题、分类、作者与来源。右键或长按可保存当前展示图，点击标题可在新标签页打开展示图直链。

主题和作者支持包含或排除；标签的“任一”匹配至少一个已选标签，“全部”要求同时具有所有已选标签。
主题和作者各最多选择 32 项。无效或超限的页面链接会提示错误，清除出错条件后可重新选择，其他条件保留。
标签组合共用 32 个词项额度：同组重复标签和完全相同的条件不重复占用；不同且组合中的同名标签分别计数。
标签切换旁的“成组”把当前选择组成一组，再继续选择下一组；组内可分别选择或 / 且，组间满足任一组即可，最多 9 组。成组后选择框显示组号，同一标签可属于多组；点击分组摘要可编辑，右侧叉号删除整组。标签区可用宽度达到 720px 时，分组摘要按编号从左到右、从上到下排列为两列，较窄时为单列。过长的组合名称复用选项名称的自动滚动，组编号、或且、数量及删除按钮保持固定；悬停或聚焦暂停滚动，减少动态效果时显示省略号。最后正在编辑的非空组也会随应用提交，空组不参与匹配。多组条件可通过页面链接保存和分享。
设备区提供“不限设备”“自动判断”“横版图片”和“竖版图片”；“不限设备”不限制图片设备，“自动判断”根据访问者的 User-Agent 选择对应设备分类。页面链接保留 `device=auto`，随机 API 链接省略 device 参数，按实际请求者的设备自动判断；“不限设备”的随机链接则明确使用 `device=all`。
设备与明暗以分段按钮切换；桌面并排显示，手机上下显示，左侧目录分别定位，标题不显示选项种类数。搜索时隐藏这两个区块及其目录入口，清空搜索后恢复；已选条件继续生效。

主题、标签和作者可按名称或 slug 搜索，忽略英文大小写，也支持按顺序输入部分字符，例如 `hz` 可找到 `hangzhou`。中文名称支持全拼、首字母及混合缩写，例如“城市夜景”可用 `chengshiyejing`、`csyj`、`chengsyj` 或 `yejing` 查找，并高亮对应中文字符。支持多音字读音、拼音间空格及用 `v` 输入 `ü`；直接文字匹配排在拼音结果前，不进行拼写错误自动纠正。设备和明暗不参与搜索，搜索期间隐藏，清空后恢复完整选项。
输入法选词期间仅更新输入框中的临时文字，结果和高亮保持上一次已确认的搜索；确认上屏后再搜索。直接输入英文字母仍即时匹配拼音。
主题、标签和作者默认单行显示名称，没有显示名时显示 slug；搜索只要命中显示名（含拼音）就保持单行，即使同时命中 slug；只有未命中显示名、命中 slug 时才显示双行。普通浏览时，当前分区可见选项名称重复则显示名称与 slug 两行；名称本身已是 slug 时不重复显示。悬停保留边框高亮，聚焦不切换行数，单双行变化不播放动画。单行名称稍大，双行时名称仍明显大于 slug，卡片采用较紧凑的纵向留白，单双行切换时高度保持不变，数量在右侧显示为“× 张”；超长文本采用与首页相同的自动滚动，悬停或聚焦时暂停，减少动态效果时以省略号显示超长文本，搜索只高亮匹配文字。三类选项统一使用等宽网格，以 240px 为最小卡片宽度按内容区可用空间自动增减列数；不足 240px 时单列适应容器。搜索结果变少时保持列宽，宽屏弹窗最大宽度为 1180px，与后台上传 / 导入弹窗同级。各区匹配方式及标签“成组”控制区靠右，窄屏换行后仍右对齐。
极窄屏（宽度不超过 350px）统一隐藏主题、标签和作者卡片的前置图标，目录图标保留，长文本继续自动滚动。
主题的“未设置”表示没有主题的图片。左侧目录定位右侧连续区块，滚动时高亮随位置变化。
主题、标签和作者的选项只展示全图库中有可展示图片的项目，不因当前筛选组合匹配到零张而隐藏。已有链接中的零匹配标签条件仍可识别，也可从已选栏移除。
与首页一致，数量为 0 的未选项不可新增选择，已选项仍可取消。统计更新中、失败或数量未知时暂停新增选择，保留取消、清空和“不限”操作。
已选条件栏支持左右箭头、鼠标滚轮和触屏横向滑动，点击条件可移除；成组标签按组显示编号，组内“或”用 `/`、“且”用 `&` 连接，点击移除只删除这一组，其他组的同名标签保留。新增选择后平滑滚到对应条件，过长的标签组定位到末尾以显示最新加入的标签，不改变输入焦点。左右箭头固定在滚动区外，不遮挡条件，到达边缘时置灰并保留位置；仍有隐藏条件的一侧保留轻微半透明渐隐。它不作为文本输入框。
筛选变化后立即更新统计；加载期间保留上次数量，仅由“已选”栏下方的蓝色光带表示正在刷新，底部说明固定显示“应用后更新展映 / 画廊”。统计失败时再显示失败提示并提供重试，保留的旧数量仅供参考。
首次打开时，光带等待弹窗入场完成再播放，并从边缘渐入、渐出；短请求完成后播完当前一轮再退场，数量按返回时间即时更新。减少动态效果时静态显示，命中有效缓存且无需请求时不播放。
主题、标签和作者选项旁数字随筛选条件动态更新，设备与明暗的数量可在桌面悬停提示中查看。主题和作者数量不计入本类别条件。与首页一致，标签“或”模式不计入已选标签；“且”模式计算当前组已选标签与候选标签的交集，每选一项便收窄剩余选项，零张未选项不可新增。成组后，每个非空组右侧显示该组在当前设备、明暗、主题和作者条件下的图片总数；各组可能包含同一张图片，不能直接相加。底部显示全部组合并去重后的完整匹配数量，统计暂不可用时仍可应用合法条件。
选择、移除和已选条件栏的“清空”只修改弹窗草稿；“查看图片”或“应用到展映”确认后一次更新页面，取消保留原条件和位置。
工具栏“分享”提供两个可独立复制的链接：页面链接保留当前已应用筛选、排列顺序和展映模式；随机 API 链接按同一筛选条件随机获取图片。嵌入模式的页面链接指向主站对应的画廊或展映页面，并显示提示。页面链接不保存滚动位置、暂停状态或当前随机图片批次。
筛选入口右侧的“清空”直接清空全部已应用条件，保留排序与展映模式；出现无效标签提示时，清空标签条件后重新选择。

展映支持 `/show?mode=waterfall` 与 `/show?mode=float`；省略或填写无效模式时使用站点默认值。
鼠标移到窗口顶部可唤出导航，键盘焦点位于导航内时保持展开。自动播放时，离开导航后会再次隐藏。

## 图片与嵌入

“当前展示图”是站点保存的标准化图片；另行登记的外部原图仅供管理员访问。
缩略图加载失败不会触发图片修改或存储修复。

站点可提供 `/embed/home`、`/embed/show` 和 `/embed/gallery` 用于嵌入其他页面。
嵌入展映保留同一响应式工具栏、筛选弹窗、详情和播放控制，也支持 `mode=waterfall` 或 `mode=float`。
是否允许嵌入以及允许哪些站点，由实例配置决定。

需要程序化取图时，使用主站 `/random`，参数与示例见[随机图 API](../random-api.md)。
图片路径、公开地址与缓存规则见[主机与图片资源](../image-resources.md)。

## 权限边界

普通用户不能上传、编辑、恢复或删除图片，也不能修改词表与实例配置。
管理员登录后可获得对应管理入口，权限始终由服务端确认。
更详细的页面交互见[公开浏览流程](../flows.md#公开浏览与图片出口)，访问边界见[安全](../security.md)。
