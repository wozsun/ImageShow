# 普通用户指南

普通用户是直接访问公开站点的人，不需要后台账号。公开页面只提供浏览、筛选、分享与
随机图片读取，不允许修改图片、词表或实例配置。

## 可以完成的任务

- 从首页进入推荐内容，或在画廊按设备、亮度、主题、标签和作者筛选图片。
- 打开图片详情，查看标题、分类、作者和来源；通过浏览器原生右键或长按菜单保存当前展示图，
  并在站点启用且图片另有登记原图时使用“原图”出口。
- 使用站点提供的嵌入页；是否开放由实例配置决定。
- 调用主站 `/random` 取得随机图片、重定向或 JSON 结果。

公开首页、画廊和详情固定使用暗色外观。图片缩略图无法加载时只显示统一损坏图标；
这类读取不会触发存储修复或对象写入。
“保存当前展示图”保存的是详情中正在显示的站点标准化图片；“原图”按钮会在新标签页打开
图片记录中另行登记的外部原图。站点关闭按钮时仍可保存当前展示图。

## 从这里开始

1. 打开站点根地址、`/home` 或 `/gallery`。
2. 需要组合筛选时使用画廊工具栏；主题、标签和作者支持包含或排除。
3. 需要程序化取图时阅读[随机图 API](../random-api.md)。
4. 需要理解主站与 `static.*` 资源出口时阅读[主机与资源子域](../subdomains.md)。

## 权限边界

公开页面不会因为浏览器里存在后台登录提示而直接授予管理能力。只有服务端确认管理员
会话后，图片详情才可能显示相应管理入口；伪造本地提示不会取得数据或写权限。普通用户
也不能访问后台 API、上传图片、恢复回收站内容或执行检查维护。

完整公开读取、详情与缓存流程见[功能与流程](../flows.md#公开浏览与图片出口)，认证与
公开入口边界见[安全](../security.md)。
