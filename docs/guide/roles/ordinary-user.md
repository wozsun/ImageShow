# 普通用户指南

普通用户是直接访问公开站点的人，不需要后台账号。公开页面只提供浏览、筛选、分享与
随机图片读取，不允许修改图片、词表或实例配置。

## 可以完成的任务

- 从首页进入推荐内容，或在展映 / 画廊按设备、亮度、主题、标签和作者筛选图片。
- 在展映的 `waterfall` 与 `float` 模式间切换，并在乱序、最新、最旧三种数据顺序间切换。
  `waterfall` 可暂停自动巡航、全向拖动、滚轮 / 双指缩放并逐列调整图片大小。同屏图片增多、超过默认列数的三倍时，
  会提示“继续显示更多图片会占用更多内存和 GPU，可能会**卡顿掉帧**。”可以取消或继续，确认后本次浏览不再重复提示。
  手动运动结束后立即恢复巡航。按钮放大缩小、Ctrl + 滚轮和双指缩放不计入导航滚动；
  两种模式在桌面鼠标向上拖动时仍收起导航，向下拖动及松手惯性不唤出；滚轮和移动端上下拖动保留导航显隐。
  `float` 暂停自动漂浮后仍可上下拖动或滚轮
  连续向上下两侧滚动，双向补图和预取，快速反向立即响应新方向，松手后保持暂停；已回收区域重新取图，不保留历史画面。
  可通过按钮或 Ctrl + 滚轮调整尺寸。每档混排目标宽度 50%–130% 的图片，放大后也会保留
  较小图片填补空位，并按混合面积调整数量；上浮时缓慢横移和轻微旋转，持续避让局部拥挤区域。
  鼠标离开画布或浏览器窗口失焦后清除图片悬停，重新进入画布时恢复响应。
  导航收起时，左右底部按钮降至 30% 不透明度；底部提示使用偏白的浅灰蓝文字与较深的灰色描边，整体保持显示并降至 20%；
  导航出现、鼠标靠近任一侧按钮或键盘聚焦按钮时恢复到完整不透明度。
  鼠标停在已展开的主导航或筛选栏内，或焦点仍在其中时，导航保持展开；鼠标与焦点都离开后，
  只有展映正在自动播放时才重新计满三秒自动隐藏。暂停播放取消计时，恢复播放后重新计时；
  画廊没有空闲自动收起，保留滚动显隐。移动端关闭筛选后，触摸残留的悬停和按钮焦点不会阻止导航收起，
  键盘操作期间仍保护可见焦点。嵌入页的筛选栏遵循同一规则。
- 打开图片详情，查看标题、分类、作者和来源；通过浏览器原生右键或长按菜单保存当前展示图，
  并在站点启用且图片另有登记原图时使用“原图”出口。
- 使用站点提供的 `/embed/home`、`/embed/show` 和 `/embed/gallery` 嵌入页；是否开放由实例配置决定。
  嵌入展映省去主导航，保留筛选、详情与底部操作，可用 `/embed/show?mode=waterfall` 或
  `/embed/show?mode=float` 指定模式；未带参数时读取默认配置，手动切换模式仍保留嵌入路径。
- 调用主站 `/random` 取得随机图片、重定向或 JSON 结果。

公开首页、展映、画廊和详情固定使用暗色外观。图片缩略图无法加载时，展映保留深色占位，其他公开页显示损坏图标；
这类读取不会触发存储修复或对象写入。
“保存当前展示图”保存的是详情中正在显示的站点标准化图片；“原图”按钮会在新标签页打开
图片记录中另行登记的外部原图。站点关闭按钮时仍可保存当前展示图。

## 从这里开始

1. 打开站点根地址、`/home`、`/show` 或 `/gallery`；实例只显示已启用页面，关闭的固定路径会回退
   到其他公开页。三页均关闭时根地址返回 404，但 `/random` 与 `/admin` 仍可独立访问。
   `/show?mode=waterfall` 与 `/show?mode=float` 可直接打开指定展映模式；省略或写入无效值时使用
   实例配置的默认模式，地址栏保持原样。点击右下角模式链接后，地址栏始终显示所选模式的
   `mode` 参数，即使切回实例默认模式也会保留；后续修改筛选或顺序不会清除已选择的模式参数。
2. 需要组合筛选时使用展映或画廊的共用工具栏；“全部设备”展示所有图片并生成显式 `device=all` 的随机
   链接，“自动设备”按浏览器 User-Agent 选择桌面或移动图片，主题、标签和作者支持包含或排除。
   “清空筛选”（移动端显示“清空”）会一次移除这五项，并让画廊列表与随机图片链接同步恢复
   缺省状态；它不会改变画廊排序或展映三态顺序，已展开的移动筛选面板也会保持展开。
3. 需要程序化取图时阅读[随机图 API](../random-api.md)。
4. 需要理解主站与 `static.*` 资源出口时阅读[主机与资源子域](../subdomains.md)。

## 权限边界

公开页面不会因为浏览器里存在后台登录提示而直接授予管理能力。只有服务端确认管理员
会话后，图片详情才可能显示相应管理入口；伪造本地提示不会取得数据或写权限。普通用户
也不能访问后台 API、上传图片、恢复回收站内容或执行检查维护。

完整公开读取、详情与缓存流程见[功能与流程](../flows.md#公开浏览与图片出口)，认证与
公开入口边界见[安全](../security.md)。
